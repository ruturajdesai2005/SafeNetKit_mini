SafeNetKit – Cybersecurity Toolkit

SafeNetKit is a Python-based desktop application built to introduce and demonstrate essential cybersecurity concepts in an easy-to-understand and interactive way. Designed with a simple and user-friendly Tkinter GUI, this project is perfect for students, beginners, and enthusiasts looking to learn about cybersecurity fundamentals through practical implementation.

The toolkit provides a safe, controlled environment to explore common security techniques, password management, and phishing detection, making it a great educational resource and mini-project for portfolio building.

🔹 Key Features
🔑 1. Password Generator

Creates strong and randomized passwords based on user input (name, birthdate, mobile number).

Utilizes random character selection and symbols to increase password strength.

Demonstrates best practices in secure password creation.

🔍 2. Brute Force Simulator

Simulates brute-force password attacks to demonstrate how attackers may crack weak passwords.

Displays the number of attempts and time taken to find the password.

Helps users understand the importance of strong password choices.

🔐 3. Login System

Allows users to register and log in with credentials.

Implements a basic hashing technique (character shifting) to store passwords securely.

Introduces authentication concepts in a simple way.

🕵️ 4. Phishing URL Detector

Analyzes URLs for common phishing indicators, such as:

Excessive use of - or @ symbols.

URLs with IP addresses instead of domain names.

Helps users identify suspicious websites before visiting.

🤖 5. CAPTCHA Generator

Generates random CAPTCHA codes for verification.

Offers a refresh option to generate new codes.

Demonstrates a simple way to prevent automated scripts or bots.

📌 Purpose of the Project

This project was developed as a mini-project for learning purposes, combining Python programming, GUI development, and cybersecurity concepts. It’s designed to:

Teach users about common security measures.

Demonstrate vulnerabilities like weak passwords and phishing attacks.

Provide an engaging, hands-on way to explore cybersecurity fundamentals.

🚀 How It Works

Clone or download the repository.

Run the Python script:

python SafeNetKit.py


Use the GUI to explore:

Generate secure passwords.

Test brute-force simulations.

Register and log in to the local system.

Analyze phishing URLs.

Verify CAPTCHA challenges.
